# 保免攔除（1867；Bodleian Sinica 2044） / Bao mian lan chu [Preventing and averting illness]: Transcription dataset

《保免攔除》（Bao mian lan chu；1867）是 Frederick Porter Smith 的晚清漢語醫學與日常保健小冊，牛津 Bodleian Libraries 藏本 Sinica 2044 著錄刊地為漢皋（Hankow），題頁署寶善居舍藏板。書中討論居室、飲食、精神與身體活動、潔身，以及內科、外科、眼科、婦人科與保嬰，並將健康論述與基督教語彙相連，可供醫學翻譯、傳教士出版與晚清生活史研究。本資料集依該藏本21幅數位影像，提供36個指定物理面的AI初錄，包含題頁、序、正文、附錄、版心及一面原框正文空白面，以TXT、JSON及TEI XML保存字串、疑讀與原圖對應。尚未經人類全文雙校或專家審定，疑讀與殘缺邊字已另行標記。

版本0.1.0。整理：曲宸宇／Chu, Chen-Yu（[ORCID](https://orcid.org/0009-0003-9738-6914)）；帳號poplolioi11。
